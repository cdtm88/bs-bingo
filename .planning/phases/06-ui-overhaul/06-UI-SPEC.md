# Phase 6 — UI Design Contract

> Visual and interaction contract for Phase 6 (UI Overhaul — dual-mode theming: SFW "Buzzword Bingo" + NSFW "Bullshit Bingo"). Generated by gsd-ui-researcher, verified by gsd-ui-checker.

**Scope:** Dual-mode design system (SFW `[data-theme="sfw"]` default, NSFW `[data-theme="nsfw"]` opt-in). No new gameplay. All 15 existing components in `src/lib/components/` are themed via CSS custom property overrides on `<html>`. SFW visuals are frozen at the Phase 1 baseline; NSFW is the new visual work. Copy swaps per theme via a new `src/lib/copy.ts` module. One new component (`BoardHeader.svelte`) for the B-U-L-L-S header in NSFW mode.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | none (Tailwind v4 + `@theme` tokens, no component library — shadcn not applicable, stack is SvelteKit + Svelte 5) |
| Preset | not applicable |
| Component library | none — 15 first-party Svelte components under `src/lib/components/`, unchanged in Phase 6 except for theme-conditional styling. One new component: `BoardHeader.svelte`. |
| Icon library | `lucide-svelte` ^0.454.0 (existing). Phase 6 adds: `briefcase` (💼 equivalent — used on the "Professional Mode" toggle). |
| Font | Inter Variable (body/label/heading) + Space Grotesk Variable (display/wordmark/room code/board header). Unchanged from Phase 1 — Space Grotesk reads as retro bingo-hall poster on parchment, per CONTEXT D-08. |

**Theming mechanism (CONTEXT D-12, D-13):**
- Default `[data-theme="sfw"]` on `<html>` — Phase 1 tokens unchanged.
- `[data-theme="nsfw"]` override block in `src/app.css` swaps all `--color-*` tokens.
- Theme store at `src/lib/stores/theme.svelte.ts`: `$state<'sfw' | 'nsfw'>('sfw')`, `localStorage` key `theme`, SSR-guarded.
- Copy module `src/lib/copy.ts` — reactive object `copy.*` driven by the theme store. Components import `copy` and read `copy.homeTagline`, `copy.startButton`, etc.

## Spacing Scale

Declared values (multiples of 4) — **unchanged from Phase 1**. No new tokens in Phase 6.

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon-to-label gaps, chip padding |
| sm | 8px | Compact element spacing, toggle internal padding |
| md | 16px | Default element spacing, button internal padding |
| lg | 24px | Section padding, card interiors |
| xl | 32px | Major layout gaps |
| 2xl | 48px | Vertical spacing between hero and CTA group |
| 3xl | 64px | Page-level desktop spacing |

**Exceptions (unchanged from Phase 1):**
- **44px minimum tap target** for all interactive elements (BOAR-07). Applies to the new Professional Mode toggle.
- Container max-widths: home/modal 480px, lobby 640px, board 720px.

**Phase 6 additions:**
- **Toggle placement offset:** fixed bottom-right corner on mobile (<640px), 16px from both edges (safe above iOS home-indicator area). On ≥640px, toggle lives in a persistent page footer, right-aligned, with 24px horizontal page padding. Claude's discretion per CONTEXT, picked bottom-right-fixed on mobile to avoid board-cell overlap while keeping it one-thumb reachable.
- **Board header row height (NSFW only):** 48px — large enough for the B·U·L·L·S display type to breathe above the grid.

## Color

Two themes, identical roles, different values. 60/30/10 split preserved in both.

### SFW theme (`[data-theme="sfw"]`) — default, unchanged from Phase 1

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#0F0F14` near-black | Page background |
| Secondary (30%) | `#1A1A23` surface + `#2A2A36` divider | Cards, inputs, roster rows |
| Accent (10%) | `#F5D547` bingo yellow | Primary CTA, room code, host crown, win-line pulse, wordmark dot |
| Destructive | `#F87171` red-coral | Error page icon, destructive confirms |

**SFW ink:** primary `#F5F5F7`, secondary `#A1A1AA`, disabled `#52525B`, inverse `#0F0F14` (on accent).

### NSFW theme (`[data-theme="nsfw"]`) — opt-in, per CONTEXT D-08

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#F5EDD6` warm parchment | Page background |
| Secondary (30%) | `#E8D9B0` manila tan + `#C9A96B` warm gold divider | Cards, surfaces, borders |
| Accent (10%) | `#D4520A` burnt orange | Primary CTA, room code, host crown, dauber stamp, win-line pulse, wordmark dot |
| Destructive | `#C0392B` deep red | Error page, destructive confirms |

**NSFW ink:** primary `#2C1810` espresso brown, secondary `#7A4F2A` mid brown, disabled `#B8956A` light tan, inverse `#F5EDD6` parchment (on accent buttons).

### Accent reserved for (BOTH themes — list is identical, values differ):

1. Primary CTA button fill ("Create a game" / "Start the suffering" / "Do it again", etc.)
2. Room code display text in lobby header
3. Host crown icon fill
4. **Dauber stamp** overlay on marked board cells (NSFW only — SFW keeps the subtle fill from Phase 3)
5. Win-line pulse ring (yellow in SFW, burnt orange in NSFW — same animation)
6. Decorative dot after the wordmark on home hero
7. Confetti palette tint (NSFW: burnt oranges + browns; SFW: existing defaults)

**Accent is NOT used for:** input focus rings, hover states on neutral buttons, links, roster highlights, secondary CTAs. Focus rings use a 2px outline in `--color-ink-secondary` offset 2px in both themes.

### Contrast audit (WCAG AA floors — both themes)

**SFW (unchanged, passes AAA):** already audited in Phase 1 UI-SPEC.

**NSFW contrast:**
- Primary text `#2C1810` on `#F5EDD6`: **13.8:1** — passes AAA
- Primary text `#2C1810` on `#E8D9B0`: **10.2:1** — passes AAA
- Secondary text `#7A4F2A` on `#F5EDD6`: **5.9:1** — passes AA (body + large text)
- CTA text `#F5EDD6` (inverse) on accent `#D4520A`: **4.8:1** — passes AA
- Destructive `#C0392B` on `#F5EDD6`: **5.1:1** — passes AA
- Disabled text `#B8956A` on `#F5EDD6`: **2.2:1** — intentionally low-contrast (disabled role); must be paired with the `cursor: not-allowed` + opacity treatment already used in SFW.

## Interaction Contracts

### Professional Mode toggle (new in Phase 6)

**Component:** `ThemeToggle.svelte` — persistent, appears on every route (home, modal, lobby, board, end, error page).

**Placement:**
- Mobile (<640px): `position: fixed; bottom: 16px; right: 16px; z-index: 50;` — outside the main content flow so it never overlaps board cells.
- Desktop (≥640px): inside a page footer, right-aligned, with 24px page padding.

**Visual:** Pill-shaped switch, 44px tall (tap target), 16px horizontal padding. Contains:
- `briefcase` icon (lucide-svelte) 16px
- Label text `Professional Mode` (Label 14px/600)
- Switch indicator (12px circle, slides 20px on toggle)

**States and semantics (CONTEXT D-05):**
- **ON = SFW** (labeled state, the "cover story") — switch right, indicator filled with `--color-accent`.
- **OFF = NSFW** — switch left, indicator filled with `--color-ink-secondary`.
- Default on first visit: ON (SFW) per CONTEXT D-03.

**Interaction:**
- Default: background `--color-surface`, border `--color-divider` 1px.
- Hover: border brightens one step (SFW `#3A3A48`, NSFW `#B08B4F`).
- Active/pressed: translateY(1px), no shadow.
- Focus-visible: 2px outline `--color-ink-secondary` offset 2px.
- Click/tap toggles theme immediately. **No confirmation.** No transition animation on palette swap (instant — per CONTEXT Claude's Discretion).
- On toggle: `localStorage.setItem('theme', nextTheme)`; theme store applies `data-theme` to `document.documentElement`.

**Accessibility:**
- `role="switch"`, `aria-checked="true|false"`, `aria-label="Professional Mode"`.
- Keyboard: Space/Enter toggle.
- Screen reader announces `Professional Mode, on` / `Professional Mode, off`.

### BoardCell dauber stamp (NSFW only, per CONTEXT D-10)

- SFW behaviour (unchanged from Phase 3): subtle background fill + strike-through on the word.
- NSFW: overlay a 72% opacity burnt orange (`#D4520A`) circular dauber stamp, ~85% of the cell's min dimension, centred. Implementation: absolutely-positioned `<span>` with a hand-drawn-style SVG background (slightly irregular circle, not a perfect `border-radius`) so it reads tactile. Word text stays black/espresso and legible underneath.
- `prefers-reduced-motion`: stamp appears instantly without the 120ms scale-in animation used in SFW.
- Win-line ring: SFW keeps yellow pulse from Phase 4; NSFW swaps to burnt orange pulse (same keyframes, different colour) — implementation: extend `@keyframes winLinePulse` in `app.css` to read `var(--color-accent)` so one animation covers both themes.

### Blank board cell texture (NSFW only, Claude's discretion)

- SFW: solid `--color-surface` fill (unchanged).
- NSFW: `--color-surface` base (`#E8D9B0`) with a very subtle diagonal crosshatch via CSS `repeating-linear-gradient` at 15% opacity using `--color-divider` — reads as "blank bingo card cell" without becoming noisy. Alternative considered (dot texture) rejected because it competes visually with the dauber stamp.

### Confetti palette (NSFW only, Claude's discretion)

- SFW: existing `canvas-confetti` defaults from Phase 4.
- NSFW: custom colour array `['#D4520A', '#C9A96B', '#7A4F2A', '#F5EDD6', '#2C1810']` — burnt orange, gold, brown, parchment, espresso. Same count, same physics.

### All other interactive contracts

Unchanged from Phase 1 (buttons, inputs, modals, banner). Only the colour values swap via custom property overrides — state behaviour is identical across themes.

## Motion & Animation

Phase 1 motion contract is preserved. Phase 6 additions:

| Moment | Motion |
|--------|--------|
| Theme toggle flip | Switch indicator slides 20px in 150ms ease-out. Palette swap is instant (no cross-fade on colour tokens — per CONTEXT Claude's Discretion). |
| Dauber stamp appear (NSFW) | Scale 0.6→1 + opacity 0→0.72 over 120ms ease-out. Instant under `prefers-reduced-motion`. |
| Win-line pulse (both themes) | Existing `winLinePulse` 1200ms loop, now reads `var(--color-accent)` so the colour tracks the theme. |
| Confetti (NSFW) | Identical physics to SFW, recoloured palette only. |

Respect `prefers-reduced-motion: reduce` — switch indicator slide collapses to 0ms, dauber stamp appears instantly.
