## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-06-05 | Tampering | ThemeToggle onclick | accept | Only effect is a localStorage write + data-theme attribute — no privilege change, no server call. Already mitigated by T-06-01 (enum validation on read). |
| T-06-06 | Information Disclosure | document.title reactive update | accept | Title reflects copy.brand which is a hardcoded string ("Buzzword Bingo" / "Bullshit Bingo"); no user content. |
