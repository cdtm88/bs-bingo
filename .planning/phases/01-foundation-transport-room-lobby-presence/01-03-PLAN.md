Build the UI chrome: a design-system component kit (Button, TextInput, Modal, Badge, PlayerRow, Banner, ErrorPage), a clipboard helper with graceful failure, the global layout, the home page with both create and join flows, and the `/join/[code]` share-link route with PRE-MODAL existence validation.

**Review Feedback Addressed (from 01-REVIEWS.md):**
- **MEDIUM — Join flow does not validate room existence before navigating:** `/join/[code]/+page.ts` load function calls `GET /api/rooms/{code}/exists` BEFORE the modal mounts. On 404, redirect to `/room/{code}?error=not-found` (Plan 04's error page handles the query). User never enters a name for a dead room.
- **MEDIUM — Clipboard API needs fallback UX:** New `src/lib/util/copyToClipboard.ts` helper returns `'ok' | 'fail'`. Detects secure-context + permission; falls back to a hidden `<textarea>` + `document.execCommand('copy')` for older browsers; surfaces 'Copy failed' inline to consumers (wired in Plan 04 lobby). Applies to share-code/share-link buttons that appear in the lobby.
- **LOW — Accessibility (modal focus management, labelled inputs):** Modal implements a real focus trap (first/last focusable cycling), sets `aria-modal="true"` + `aria-labelledby`, restores focus to the invoking element on close, and dismisses on both Esc AND backdrop click. TextInput associates `<label for={id}>` with an explicit id, and the error element uses `role="alert"` so screen readers announce validation failures. Tested via Playwright keyboard-navigation check in Plan 05.

Output: A user can land on `/`, create a room (POST succeeds), enter a display name, and reach `/room/{code}` — where Plan 04's lobby renders the live roster. Dead share-links short-circuit to the error page before any name-entry UI.

       ```ts
       export async function copyToClipboard(text: string): Promise<"ok" | "fail"> {
         // Primary path — requires secure context.
         if (typeof navigator !== "undefined" && navigator.clipboard?.writeText) {
           try { await navigator.clipboard.writeText(text); return "ok"; } catch { /* fall through */ }
         }
         // Fallback: hidden textarea + execCommand.
         if (typeof document === "undefined") return "fail";
         const ta = document.createElement("textarea");
         ta.value = text;
         ta.setAttribute("readonly", "");
         ta.style.position = "fixed";
         ta.style.opacity = "0";
         ta.style.pointerEvents = "none";
         document.body.appendChild(ta);
         ta.select();
         try {
           const ok = document.execCommand("copy");
           return ok ? "ok" : "fail";
         } catch {
           return "fail";
         } finally {
           ta.remove();
         }
       }
       ```
