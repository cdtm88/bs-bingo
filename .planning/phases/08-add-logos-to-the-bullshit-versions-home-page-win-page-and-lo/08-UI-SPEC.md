|------|------|--------|-------------|-------------|

- Brand-dot `.` colored with `var(--color-accent)`, matching hero pattern.
- Implementation discretion (CONTEXT D-01): either add `size="medium"` prop to `Logo.svelte` or use inline classes in `EndScreen.svelte`. Prefer the prop — API stays clean and the new size is reusable.

**Accent (`--color-accent`) reserved for:**
1. Primary CTA background (`Button variant="primary"`) — `createCta`, `joinCta`, modal submit, `playAgain`.
2. Logo icon fill (all three sizes: compact, **medium (new)**, hero) and the brand-name trailing `.`
3. Winning-word pill background (`EndScreen` winning-words cluster).
4. Win-line pulse halo (`[data-win-line="true"]` box-shadow on Board).
5. BINGO / CALLED IT headline text color on winner EndScreen.
6. Dauber stamp fill + ink-bleed ring (NSFW board cells).

Accent is NOT used for: body copy, icon-button surfaces, join-code input borders, helper text, the `or` divider, or the loser subhead. Phase 8 does not extend the accent to any new elements.

**Destructive** is reserved for form error text only (`TextInput.error`). No destructive action in this phase.

## Visual Contracts — Component Changes

### `Logo.svelte` — add `medium` size

- API: `size: "hero" | "medium" | "compact"` (default `compact`).
- Icon bounds: `w-8 h-8 sm:w-10 sm:h-10`.
- Wordmark: `font-display text-[28px] sm:text-[36px] font-semibold leading-[1.1]` with accent `.` suffix.
- Layout: same centered flex row as `hero` (`flex items-center justify-center gap-2 sm:gap-3`).
- `aria-hidden="true"` on the SVG; no interactive behavior (end-screen logo is decorative, not a link).

### `EndScreen.svelte` — medium logo block

- Placement: top of `<section>`, above the existing `<h1>` (winner) / existing subhead (non-winner). Rendered on **both** winner and non-winner views.
- **NSFW-only rendering rule:** `{#if theme.current === "nsfw"}<Logo size="medium" />{/if}` — the SFW EndScreen layout stays exactly as shipped (CONTEXT D-01, D-03).
- Vertical rhythm: existing `gap-6` (24px) on parent `flex flex-col`. No added margins on the Logo element — it inherits the section gap.
- Reading order for screen readers (NSFW): Logo → `aria-live="polite"` headline → subhead → win-line icon → winning-words → consolation → CTA. The Logo's `aria-hidden` ensures no duplicate brand announcement (header already announces brand).

### `+page.svelte` — NSFW polish pass

- Replace all hardcoded strings (`"Join with code"`, `"ABC234"`, `"Your name"`, modal helper, two error messages) with `copy.*` reads.
- `or` divider: substitute `{copy.orDivider}` for the literal `or`. Keep the two flanking `<span class="flex-1 h-px bg-[var(--color-divider)]">` lines — a longer NSFW string (`or drag someone in`) simply pushes the dividers wider, which is acceptable (`flex-1` absorbs). On ≤375px mobile, verify the phrase does not wrap; if it wraps, shrink `text-sm` → `text-xs` on the divider label under a `sm:text-sm` breakpoint OR shorten NSFW copy. Planner decides based on measured behavior.
- No layout changes beyond copy; no new components, no palette shifts.

### Unchanged

- SFW EndScreen — explicit per CONTEXT D-01.
- All protocol, store, and routing logic.
- Board, BoardHeader, BoardCell, WinLineIcon visuals.
- Theme toggle, layout chrome, error pages.

## Accessibility Contract

- **Color contrast:** Text-on-accent pills (winning words, primary buttons) continue to use `var(--color-ink-inverse)` against `var(--color-accent)` — existing contrast verified in Phases 6/7 for both themes.
- **Focus rings:** No new focusable elements. Existing `focus-visible:outline-2 focus-visible:outline-offset-2` on Button stays.
- **Screen reader announcements:** `aria-live="polite"` on the win headline already handles winner/loser state change. The new logo must be `aria-hidden="true"` (decorative) so SR users hear the headline, not a second brand read.
- **Copy length:** NSFW strings must fit within existing containers at 375px viewport. `"or drag someone in"` is the longest new divider string — planner verifies it does not blow out the divider row; if it does, choose a shorter NSFW variant (e.g. `"or crash one"`).
